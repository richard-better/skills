# Health records

Builds and maintains a **records folder** from health PDFs in any language. Each PDF becomes a
**document**: a faithful Markdown transcription with frontmatter. Every lab result becomes one
row of `markers.csv`, named consistently across labs and languages. `index.md` is generated from
both and is where any reader starts.

`<skill>` below is this skill's folder. Both scripts run with `uv run`, install their own
dependencies, and print their usage with `--help`.

```
<records>/
  index.md        generated by records.py index
  context.md      written by the owner: age, sex, conditions, medications with dates, questions
  markers.csv     one row per lab result, written by records.py merge
  aliases.csv     this folder's original name -> canonical name pairs, grown by merges
  documents/
    2025-03-14_lab_example-lab.pdf    copy of the original
    2025-03-14_lab_example-lab.md     its transcription
  panels/         health-differential reports
```

## 1. Find the folders

Get the PDF folder and the records folder from the owner. For a new records folder, create
`documents/`, and ask the owner for the facts `context.md` needs: age, sex, conditions,
medications and supplements with start and stop dates, current questions. Write only what they
give.

## 2. Read the new PDFs

```bash
uv run <skill>/scripts/extract.py <pdf-folder> --list --records <records>
```

This lists each PDF not yet in the records folder, by content hash, with its page count and
sha256. A `FAIL` line is an encrypted or broken PDF; for an encrypted one, ask the owner for an
unlocked copy.

Read each PDF directly, every page: Claude Code's `Read` takes a PDF (pass `pages` ranges beyond
10 pages), and so do Gemini and other models. Reading the PDF keeps each value on its row and
shows stamps, handwriting and scans. Read every number twice, against its row. When you cannot
read PDFs, or one comes back empty or truncated, follow
[references/extraction.md](references/extraction.md).

## 3. Transcribe each document

Write `documents/<basename>.md` and copy the PDF beside it as `<basename>.pdf`. The basename is
`YYYY-MM-DD_<type>_<provider-slug>`, with `-2`, `-3` when two share a name.

```yaml
---
date: 2025-03-14          # sample collection or visit date, not the print date
type: lab                 # lab | imaging | discharge | visit | pathology | procedure | prescription | vaccination | other
provider: Example Lab     # as printed
title: Chemistry and blood count
clinician: Dr. Jane Doe   # optional
language: hu              # ISO 639-1 code of the original
source: 2025-03-14_lab_example-lab.pdf
sha256: <from extract.py>
extraction: pdf           # pdf | text | vision | mixed: how the content was read
summary: Fasting glucose high (6.4), ferritin low (18), mild microcytic anaemia.
---
```

The summary is one English line naming what a clinician would look at first. The body is a
**faithful** transcription:

- Original language and wording. Every test, value, unit, flag, range, date, finding and
  conclusion, exactly as printed, typos included. Lab tables become Markdown tables.
- Leave out page furniture: repeated headers and footers, barcodes, page numbers.
- Replace national ID, insurance and passport numbers with `[ID]`. Keep the name and birth date.
- Mark what you cannot read `[illegible]`.

Done when every PDF from step 2 has its document or a `FAIL` reason, and each document's
frontmatter is complete.

## 4. Stage and merge the markers

For every document with lab results, including results quoted in discharge letters, write one
row per result to `<scratch>/rows.csv` with the columns `original_name, value, unit, ref_range,
flag, date, source`. Add `name` for a test the analyte table does not know, or where its name is
wrong for this report, such as a method-specific test or a D3-only vitamin D.

- Write `value` and `ref_range` with decimal dots.
- Map the report's flags: `+`, `↑`, `H` to `H`; `-`, `↓`, `L` to `L`; `*` to `A`; critical to
  `HH` or `LL`. A qualitative result (`positive`, `negatív`, `++`) is the `value`; flag it `A`
  only when the report marks it abnormal. Leave the flag empty when the report prints none.
- Use the sample's collection date. A report with several draws gets one row per draw.
- Blood is the default specimen. Prefix any other: `Urine protein`.
- Name an unknown test with the canonical English name a clinician would search for, keeping a
  units-specific name like `Neutrophils %` apart from `Neutrophils`. Find its LOINC with
  [references/loinc.md](references/loinc.md).

```bash
uv run <skill>/scripts/records.py merge <records> <scratch>/rows.csv
```

Rerun until it exits 0. Check each note it prints against the page: a flag the report and range
disagree on, a unit unusual for the name, or two values on one day usually means a misread or a
wrong name.

## 5. Index and check

```bash
uv run <skill>/scripts/records.py index <records>
uv run <skill>/scripts/records.py check <records>
```

Done when `check` exits 0 and, for each document, its lab tables and `markers.csv` hold the same
number of results (`grep -c` the source path).

## 6. Report

Tell the owner: documents added (date, type, provider, summary), PDFs skipped and why, flagged
results, and `check` warnings. Name results that moved across the reference range since their
previous value.
