# Default UI taste

The taste `ui-judge` uses when the user supplies none. Distilled from the parts of Emil
Kowalski's [`emil-design-eng`](https://github.com/emilkowalski/skills/tree/main/skills/emil-design-eng)
and [`apple-design`](https://github.com/emilkowalski/skills/tree/main/skills/apple-design) that
show in a still screenshot. Their motion rules need a recording, not a shot.

To use your own, write a file in the same format, as in [custom-taste.md](custom-taste.md). It
replaces this one whole, so copy what you want to keep.

- **The most important thing is the most obvious.** Order, spacing and contrast make the primary
  content win; emphasis comes from weight before size or colour.
- **Simple, not minimal.** Every element earns its place, and context that answers a question
  (time remaining, a count) stays. The common path shows first, advanced options one level
  deeper.
- **Type changes shape with size.** Large headings get tight leading and slightly negative
  tracking, body text comfortable leading and tracking near zero. One typeface, the system font
  unless there is a reason.
- **Every value can be defended.** Spacing, radii and alignment sit on one scale; nothing is off
  by a few pixels.
- **Proximity means relationship.** A control sits next to what it changes, and groups read as
  groups through spacing before borders or boxes.
- **Specific labels.** Things are named for what they hold ("Library"), not a vague umbrella
  ("Home"). A control that needs a caption to explain it is in the wrong place.
- **Every screen answers where am I, where can I go, and how do I get out.**
- **Familiar before novel.** Things that look the same behave the same and live in the same
  place; platform conventions hold unless the new pattern is clearly better.
- **Depth shows hierarchy.** Floating chrome reads as a layer over content, heavier surfaces
  separate structure and lighter ones draw the eye to actions. No translucent surface sits on
  another, and a soft edge where content meets floating chrome beats a hard divider.
- **Text stays legible on any surface.** Secondary text keeps its contrast; text over a material
  gets more contrast and weight, not a flat grey.
- **Colour carries meaning.** Accent marks state or action, never decoration, and the screen
  holds up in light and dark.
- **Every state is designed.** Empty, loading, long content and error look intended, and an
  error sits next to its cause.
- **One mood.** A dense tool looks crisp, a personal moment warmer; nothing on the screen looks
  borrowed from another app.
- **Delight is the sum, not a layer.** Gradients, ornaments and illustrations added to make a
  screen feel finished count against it.
