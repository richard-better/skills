## Install

With [`skillsfile`](https://github.com/richard-better/skillsfile), add these to your
`skills.yaml` and run `npx skillsfile`:

```yaml
x-emil: &emil
  source: emilkowalski/skills

skills:
  # cathrynlavery/diagram-design
  diagram-design: cathrynlavery/diagram-design

  # cursor/plugins
  bro:
    source: cursor/plugins
    path: pstack/skills/bro
  thermo-nuclear-code-quality-review:
    source: cursor/plugins
    path: cursor-team-kit/skills/thermo-nuclear-code-quality-review
  unslop:
    source: cursor/plugins
    path: pstack/skills/unslop
  verify-this:
    source: cursor/plugins
    path: cursor-team-kit/skills/verify-this

  # emilkowalski/skills
  emil-animate:
    <<: *emil
    path: skills/animate
  emil-apple-design:
    <<: *emil
    path: skills/apple-design
  emil-design-eng:
    <<: *emil

  # humanlayer/skills
  show-me: humanlayer/skills

  # mattpocock/skills
  grilling: mattpocock/skills
  writing-for-agents: mattpocock/skills

  # shadcn/improve
  improve: shadcn/improve

  # t3dotgg/tstack
  babysit-pr: t3dotgg/tstack
  full-send: t3dotgg/tstack
  sol-loop: t3dotgg/tstack
```

Or install one at a time with the [`skills`](https://github.com/vercel-labs/skills) CLI, for
example `npx skills add mattpocock/skills --skill grilling`.
